Frontend

The frontend is the client-side application layer responsible for rendering the interface, managing state, and interacting with backend services.

  • Translates application state into a coherent and responsive user experience
  • Manages asynchronous data flows and user-driven interactions
  • Synchronizes local UI state with backend-provided data
  • Balances performance, accessibility, and usability constraints

At an advanced level, the frontend functions as a client-side application responsible for translating system state into a consistent user experience.

It manages asynchronous data, user interactions, and interface updates while balancing performance, accessibility, and responsiveness.

For more info check out wiki.

Backend

The backend is the server-side system that enforces application logic, security, and data flow independently of the user interface.

  • Acts as the authoritative layer for application logic and rules
  • Validates and processes all incoming requests regardless of source
  • Enforces authentication, authorization, and data integrity
  • Coordinates operations across services and persistent storage

The backend acts as the authoritative control layer that defines and enforces application rules independently of the interface.

It validates requests, manages permissions, and maintains consistency and security under concurrent usage.

For more info check out wiki.

HTML (HyperText Markup Language)

HTML defines the semantic structure of the application and serves as the foundation for accessibility, styling, and scripting.

  • Defines semantic structure and document hierarchy
  • Enables accessibility tools and predictable browser behavior
  • Serves as a stable foundation for styling and scripting layers
  • Improves maintainability through meaningful markup

HTML provides semantic structure that defines meaning, hierarchy, and intent rather than visual appearance.

This structure enables accessibility technologies, predictable browser behavior, and reliable interaction with scripts and styles.

By establishing a clear document foundation, HTML supports long-term maintainability and scalability of the interface.

For more info check out wiki.

CSS (Cascading Style Sheets)

CSS controls layout, visual systems, and responsive behavior through declarative styling rules.

  • Governs layout behavior and responsive adaptation
  • Establishes visual hierarchy and design consistency
  • Defines reusable patterns and component-level styling rules
  • Communicates state and structure through visual cues

CSS governs layout behavior, visual hierarchy, and responsive adaptation across devices and screen sizes.

It defines reusable styling patterns, constraints, and relationships that allow interfaces to scale without increasing complexity.

Through spacing, contrast, and motion, CSS communicates structure and state independently from application logic.

For more info check out wiki.

JavaScript (Programming Language)

JavaScript powers the application logic in the browser, handling state, events, and communication with the backend.

  • Coordinates user interactions and application state
  • Manages asynchronous operations and event sequencing
  • Handles communication between frontend and backend APIs
  • Ensures UI updates accurately reflect system state

JavaScript coordinates user input, application state, and backend communication within the browser runtime.

It manages asynchronous operations, event sequencing, and dynamic interface updates in response to user and server activity.

At an advanced level, JavaScript controls data flow and interaction logic rather than isolated actions.

For more info check out wiki.

PHP (Hypertext Preprocessor)

PHP is a server-side execution environment used to process requests, manage sessions, and coordinate backend operations.

  • Processes HTTP requests within the backend environment
  • Enforces security rules and session management
  • Handles data validation and backend workflows
  • Generates structured responses for frontend consumption

PHP processes HTTP requests and executes backend logic within a controlled server environment.

It manages request lifecycles, enforces authentication and authorization rules, and validates incoming data.

PHP acts as the bridge between external clients and internal application logic, producing structured responses.

For more info check out wiki.

SQL (Structured Query Language)

SQL defines how application data is structured, stored, and retrieved within a relational database.

  • Defines relational data structures and constraints
  • Maintains data integrity and consistency over time
  • Models relationships between application entities
  • Optimizes data retrieval and storage patterns

SQL defines how data is structured, related, and constrained within a relational database system.

It enforces integrity rules, represents real-world relationships, and prevents inconsistent or invalid data from being stored.

Efficient querying and indexing enable reliable access to data as application complexity and volume grow.

For more info check out wiki.
